EventBooking

A focused digital ticketing experience for discovering events, booking seats, paying securely, and receiving confirmation.

Welcome back

01 / Product

The problem

Event attendees need a simple path from discovery to a usable ticket, while organizers need visibility into events, bookings, and revenue.

For attendees

Browse events, compare details, choose a payment method, and keep a digital ticket.

For organizers

Create events, monitor capacity, and review confirmed bookings from an admin view.

02 / Experience

Designed for flow

Sign in with a verified Gmail account through Firebase Authentication.
Discover and filter active events, then open an event detail view.
Select ticket quantity and complete a card, PayPal, or M-Pesa payment.
Receive a confirmation ticket with a ticket ID and payment details.
03 / Technical

Built to extend

Frontend

Vanilla JavaScript, component templates, client-side routing, responsive CSS, dark mode, and animated transitions.

Authentication

Firebase Google sign-in with verified Gmail-only access and session restoration.

Performance

Native lazy-loaded event images, asynchronous decoding, and reduced-motion support.

Messaging

Firebase Cloud Functions call Resend for welcome and purchase confirmation emails.

04 / Readiness

Launch checklist

Enable Google sign-in and authorize local/live domains in Firebase.
Add Resend credentials and a verified sender to functions/.env.
Upgrade Firebase to Blaze to deploy Cloud Functions.
Run browser checks across login, event browsing, payment, ticket, and admin flows.
